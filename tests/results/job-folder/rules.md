# My job search rules

Your own rules, on top of the fixed guardrails (which you can read in the plugin's `reference/guardrails.md`).
Add a line whenever you tell Claude "from now on...". Newest at the bottom, with the date.

## Fixed (always on, listed here so you can see them)
- Claude never clicks a final Submit unless I say yes to that one application.
- Claude never sends a message unless I say yes to that exact text.
- Claude never types my passwords, 2FA codes, Social Security number or ID numbers.
- Claude never solves CAPTCHAs or bot checks.
- Claude never invents experience, and labels its guesses.
- LinkedIn is read-only.
- Scheduled runs only read and draft; they never send or submit.
- My pay floor is never said to anyone.
